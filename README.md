# **CCApp -.NET Core Coding Challenge**

This project was to demonstrate my skills in C# and RESTful Web API by designing and developing a web service the securely processes uploades files and provide basic reporting of this files upon request.

## Table of Content
- Features
- Installation

## Features
- Secure the file upload endpoint with an API Key authentication mechanism.
- Support for CSV, calculate a simple aggregateion
- Tracker for the number of files processed or log basic file
processing details (e.g., filename, processing time).
